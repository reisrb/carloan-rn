# CarLoan RN – Project Overview

## Architecture
- **React Native (Expo)** app built with TypeScript.
- **Supabase** backend for authentication, storage and PostgreSQL data.
- **AsyncStorage** used for client‑side caching of car photos (base64).
- **Theme system** (`src/theme/`) provides dark/light mode, design tokens and shadows.
- Navigation is handled by **React Navigation** (stack + bottom tabs).

## Core Directories
| Directory | Purpose |
|-----------|---------|
| `src/components/` | UI building blocks (FinancingCard, AddFinancingSheet, etc.). |
| `src/screens/` | Full‑screen pages (FinancingListScreen, Dashboard, Settings…). |
| `src/services/` | API wrappers around Supabase (`financingService`, `sharingService`, `imageService`). |
| `src/hooks/` | Custom React hooks (`useResponsive`, etc.). |
| `src/theme/` | Design tokens, colors, shadows, dark‑mode support. |
| `src/navigation/` | Stack and tab navigation configuration. |
| `src/lib/` | Supabase client initialization. |
| `src/types/` | TypeScript interfaces for financings, shares, payments, etc. |

## New Features Added
- **Image caching**: `imageService.getOrCachePhoto` stores car photos as base64 strings in `AsyncStorage`, dramatically speeding up subsequent loads.
- **Loading spinner enhancement**: `FinancingListScreen` now pre‑caches all images before clearing the spinner, guaranteeing a smooth initial view.
- **Improved data loading**: Parallel fetching of own and shared financings, with paid‑installment counts calculated in a single Supabase query.

## Development Workflow
1. `npm install` – install dependencies.
2. `npm run dev` – start Expo dev server (iOS/Android/web).
3. `npm run build:web` – produce a static PWA for Vercel.
4. Use `git push` to deploy via Vercel.
